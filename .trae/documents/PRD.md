## 1. 产品概述

企业会议室预约与资源调度系统，旨在解决企业内部会议室资源分配混乱、设备调度低效、预约冲突频发等问题。目标用户为企业内部员工及行政管理人员，通过数字化手段实现会议室高效预约、设备统一调度、智能冲突检测、签到管理与数据统计分析。

- 解决痛点：会议室重复预订、设备申请流程繁琐、使用率缺乏数据支撑
- 目标价值：提升会议室利用率 30%+，减少预约冲突 90%+，实现资源调度全流程数字化

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 管理员 | 系统分配 | 会议室/设备管理、用户管理、统计报表查看、所有预约审批 |
| 普通用户 | 邮箱注册/邀请码 | 会议室预约、设备申请、签到、查看个人预约记录 |

### 2.2 功能模块

1. **登录页**: 用户认证、JWT 登录、角色识别
2. **仪表盘**: 今日预约概览、会议室状态卡片、待签到提醒、使用率图表
3. **会议室管理**: 会议室列表/网格展示、筛选搜索、详情查看、新增/编辑会议室（管理员）
4. **预约管理**: 创建预约、时间冲突检测、预约列表、预约状态流转、取消预约
5. **设备管理**: 设备列表、设备申请、设备状态跟踪、设备绑定会议室
6. **签到管理**: 扫码/手动签到、签到状态统计、超时未签到自动释放
7. **统计报表**: 会议室使用率、部门预约排行、时段热力图、设备使用统计
8. **用户管理**: 用户列表、角色分配（管理员）

## 3. 核心流程

### 3.1 会议室预约流程
用户选择日期和时间段 → 系统展示可用会议室 → 用户选择会议室并填写预约信息 → 系统进行时间冲突检测 → 无冲突则创建预约，有冲突则提示冲突信息 → 预约成功后发送通知 → 会议开始前15分钟提醒签到 → 用户扫码/手动签到 → 会议结束

```mermaid

    "选择日期和时间段" --> "展示可用会议室"
    "展示可用会议室" --> "选择会议室填写信息"
    "选择会议室填写信息" --> "时间冲突检测"
    "时间冲突检测" -->|"无冲突"| "创建预约"
    "时间冲突检测" -->|"有冲突"| "提示冲突信息"
    "提示冲突信息" --> "选择会议室填写信息"
    "创建预约" --> "发送预约通知"
    "发送预约通知" --> "会前15分钟签到提醒"
    "会前15分钟签到提醒" --> "用户签到"
    "用户签到" --> "会议进行中"
    "会议进行中" --> "会议结束"
```

### 3.2 设备申请流程
创建预约时同步申请设备 → 系统检查设备可用性 → 设备可用则关联预约 → 设备不可用则提示替换方案 → 预约确认后锁定设备 → 会议结束后释放设备

### 3.3 签到管理流程
会议开始前15分钟开放签到 → 用户扫码/手动签到 → 超过会议开始15分钟未签到 → 系统自动标记为未到 → 释放会议室资源

## 4. 用户界面设计

### 4.1 设计风格
- 主色调: 深蓝色 (#1E3A5F) + 翠绿强调色 (#10B981)
- 辅助色: 暖灰背景 (#F8FAFC)、警示红 (#EF4444)、提示橙 (#F59E0B)
- 按钮风格: 圆角 (8px)、主要按钮实色填充、次要按钮描边
- 字体: 标题使用 "DM Sans"、正文使用 "Noto Sans SC"
- 布局风格: 侧边栏导航 + 顶部工具栏、卡片式内容区
- 图标风格: Lucide 线性图标，与文字搭配使用

### 4.3 响应式设计
- 桌面优先设计，最小宽度 1280px
- 侧边栏可折叠适配中等屏幕
- 移动端隐藏侧边栏，使用底部导航栏

## 5. 非功能性需求
- JWT 认证与 RBAC 权限控制
- API 接口限流（Redis 实现）
- 会议室状态缓存（Redis 缓存，5分钟过期）
- 时间冲突检测并发安全（Redis 分布式锁）
- 签到超时自动释放（定时任务）
